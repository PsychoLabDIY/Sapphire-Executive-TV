# V7.1.2 — header QA

24 November 2026 · Xiaomi TV A Pro 55 (2026)

The supplied on-device QA report returned PASS for the header-only navigation test: seven distinct controls in forward and reverse order, visible focus changes on all seven, and a return to the app dock. The nine PNG files listed in the report have matching SHA-256 digests. Each capture is 1920 × 1080. The controls are Bluetooth, HDMI 2, MSI (Moonlight), source picker, Wi-Fi, app library and options.

This is a visual and focus-navigation check, not a full functional regression suite. Bluetooth audio pairing, direct HDMI switching, streaming quality, idle-clock behavior and reboot persistence were not tested in this run. The owner previously confirmed that Moonlight connected to the MSI host, but streaming image quality remains under investigation.

V7.1.2 retains the six translucent application tiles, live clock/date, RAM and storage information, weather and the champagne-accented header. V7.1.3 is a proposed follow-up with an event-driven connected Bluetooth audio-output indicator; it is not yet verified on the TV. The indicator is not a claim about the currently selected audio route.

Only curated native images should be published; the complete QA archive and device logs are excluded.
